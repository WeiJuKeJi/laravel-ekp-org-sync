# 2026-10-04 EKP组织同步扩展开发

## 目标与环境

实现通用 Laravel Composer 扩展，依赖 IAM 可选目录，支持真实 EKP 全量、增量及定时同步。源码与测试运行于 macOS 本地，资金项目使用 path 链接；未发布、提交、推送或修改远端组织。客户实际数量与备份证据保存在资金宿主，不在通用包写客户凭据或个人资料。

## 改动

新增客户端/归一 DTO、来源加密凭据、来源租约及运行表、时间戳分页服务、完整清单核对、失败安全提交、3个命令、调度注册、管理API及23项独立回归。页面手工触发登记 requested_mode，由本地工作进程或 Laravel Scheduler 执行。暂存只在内存并限制规模；未创建客户专用投影或自动用户登录。

异常修复：空页不推进游标；同毫秒超额页面保留；失去租约禁止提交/不释放新所有者；初始化异常释放自有租约；预览共享目录验证；JSON字符串解析及错误固定码避免原始响应泄漏。

## 验证与文档

独立 Testbench Laravel13.34.0 / Spatie7.4.2 / PHPunit13.3.6：23测试114断言通过，隔离临时SQLite普通迁移。资金Laravel12宿主同步集成与完整79测试412断言通过。默认关闭IAM93测试256断言通过。命令/迁移语法及 Composer 验证、代码格式检查执行结果见宿主验收报告。正式文档为README及docs/设计方案/组织同步协议与故障恢复.md。

## 未覆盖

真实远端组织改名/停用写入实验、多节点源变更、Laravel11/MySQL/PostgreSQL、超大规模和正式cron部署未验收；本地进程持续运行不等于开机自启。无自动资金公司映射。
